# Elysium Sprint 7 demo

Browser build for Team Like's Sprint 7 presentation, November 8, 2026.

Includes the merged Sprint 7 work and natural disaster feature commit `21c6a96` (PR #17).

Open the GitHub Pages website to play. Use a desktop browser and load it before presenting.

Controls: Space pauses, D cycles speed, arrow keys move the camera, K triggers fire, and L triggers flood. Disaster tests require an eligible placed building and no open dialogue or daily report, with the game unpaused.

The first download is about 75 MB. Keep the tab open during the presentation.
